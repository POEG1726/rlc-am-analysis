# 数据、来源与复现边界

数据均来自本项目已有的台架实验。本次整备未新采集、补造或插值填充测量。A–E类别对应正式AM两批、驱动支持/极限实验、早期诊断与校准，以及采集/处理代码。

## 数据分层

| 类型 | 代表字段 | 含义 |
|---|---|---|
| 设置/读回 | `programmed_*`、`amplitude_programmed_Vpp`、量程、采样率 | 发生器设置或仪器读回；不是实际输入电压 |
| 波形提取特征 | CH1/CH2的频谱幅度、`vin_Vpk`、`H_real`、`H_imag` | 已有波形经过FFT或正弦拟合得到的特征；原波形未包含 |
| 直接响应指标 | `Hmax`、`f0_measured_Hz`、`BW_measured_Hz`、`Q_measured` | 使用实测频响与相位零点/交点提取；算法定义见对应脚本 |
| 推导量 | `Z_*`、`I_*`、`T_lower`、`T_upper` | 基于实测特征和标称5.1 Ω或比值计算 |
| 等效模型拟合 | `Rs_fit_ohm`、`L_eff_fit_*`、`C_eff_fit_*`、`complex_H_RMSE` | 模型相关参数、残差及有效性，不能等同实物元件实测值 |
| 跨重复统计 | `*_mean`、`*_sample_SD`、`*_relative_SD_percent` | 均值、样本SD（ddof=1）、100×SD/绝对均值 |

完整表结构见 [data_dictionary.csv](data_dictionary.csv)：列出每个公开CSV的全部列、单位、字段分类和说明。未知的历史辅助字段标为原有字段，而不推测其物理含义。

## 批次与文件

- `am_initial`：75条正式测量、15条频率汇总、5条端点检查。
- `am_extended`：155条正式测量、31条频率汇总、5条端点检查。
- `drive_support`：18条共振重复结果、918条频率点、18条谐波记录；实际UTC日期为2026-10-01。
- `drive_extreme`：21条共振重复结果、1139条频率/捕获审计行、21条谐波记录；实际UTC日期为2026-10-01。
- `characterization`：38条升/降幅度扫描结果、1938条频响记录、38条谐波记录、66条相对量程校准记录及其他诊断表。保留各原文件的独立用途，不与后续正式数据合并。

两个正式批次均使用5次独立sweep，端点检查不计入正式频率点的样本SD。离线入口会核对均值、SD、边带归一化、端点基线与漂移，同时检查重复键、削顶标志和通道FFT bin一致性。

## 极限实验中断与筛选

极限实验在4 Vpp、重复2期间发生VISA I/O错误。失败的传输未作为有效测量；部分频响点保留在逐点表中，随后从该重复重新开始。`drive_dependence_results.csv` 中是最终21条完成结果。

`frequency_response_raw.csv` 包含量程检查、初次中断和恢复后的点。它是特征表，不是时域波形。不要直接按幅度平均其全部1139行。

原有14张极限实验图由 `collect_drive_dependence_extreme.py` 的 `make_plots` 生成。其频响覆盖图使用 `coarse` / `fine` 扫描标签，保留有效性检查，并使用恢复后的4 Vpp重复2扫描，排除旧的中断片段。精确筛选代码随该脚本保留。该脚本的主程序是历史恢复流程；新离线入口从最终21条结果生成4张核心幅度图，不把该恢复流程当成新采集。

## 量程与拟合

早期 `vertical_scale_corrections.json` 来自同信号跨相邻量程的相对增益映射，以200 mV/div为参考；它不是可溯源的绝对幅度校准。历史摘要和脚本标明何时使用该映射。正式AM记录在固定20/10 mV/div下采集，按其原有算法保留，不追加跨批次校正。

驱动支持和极限实验的0.2 Vpp复数拟合均不可靠。源表保存 `complex_fit_success` 和 `complex_fit_reliable`：求解器成功不等于模型足够可靠。离线拟合汇总仅使用 `complex_fit_reliable=True` 的行。

## 隐私变换与可验证性

- 原始输入保持在本地，发布的是副本。
- 除时间/波形引用及JSON设备身份字段外，CSV原字段的字符串数值保持不变；不会因重新写入而降低数值精度。
- `*_utc` 时间字段转换为 `*_elapsed_s`，以**同一CSV全部相关时间字段的最早时刻**为零点。不同CSV的零点独立，不能把其相对时间直接对齐。
- `raw_waveform_filename` 转为 `waveform_id`，端点检查中的对应字段采用相同规则。编号保留sweep与测量名，删除文件夹路径和NPZ后缀；波形不包含在发布中。
- 参数JSON设备ID仅保留厂商与型号；精确扫描时刻只保留日期。
- 历史Markdown的精确UTC时刻同样只保留日期；这些笔记按原批次归档，不作为整个项目现状说明。
- `data/manifest.json` 记录每个发布数据/图片/笔记文件的SHA-256、字节数、CSV行数及字段改名。哈希对应脱敏后的文件。

公开CSV可核验跨重复统计和图表。没有原生波形，无法独立重算FFT峰值、重新估计噪声底、修改窗函数或重新解码ADC；这些边界不能由统计一致性验证代替。43张归档PNG保留原图内容，其PNG文本元数据仅含Matplotlib软件标记。
